## 页面结构

### 1. Hero（100vh）
- 视频全屏背景：`../../素材/jimeng-2026-04-15-1285-...mp4`，autoplay / muted / loop / object-fit:cover
- 底部渐变遮罩（视频→奶油色）保证文字可读
- 居中内容层：
  - logo（`../../logo 2.webp`，80px圆角）
  - 标题：`狗蛋 Max`（Noto Serif SC 900，大字）
  - 副标题：一句话简介
  - CTA 按钮：「免费下载」
  - 向下滚动箭头（小动画）

### 2. 动画状态展示（核心区）
- 大标题：「它懂你在做什么」
- 11 个状态卡片（grid 布局，3~4列）
- 每张卡片：
  - Canvas 渲染 webp 帧序列动画
  - 默认播放第 0 帧静止
  - 鼠标悬停 → 循环播放该动画
  - 状态名称 + 触发说明
- 动画目录（相对路径引用，不复制文件）：
  `待机` `完成` `搜索` `办公` `打字` `喝水` `刨地` `伸懒腰` `提起` `提醒` `闻闻`

### 3. 工作原理（极简 3 步）
- 标题：「接入只需 30 秒」
- 水平排列：事件触发 → Hook 转发 → 动画播放
- 配 code 片段展示

### 4. 下载区
- 居中单卡片
- 价格：¥0 永久免费
- 功能列表（5条）
- 大下载按钮

### 5. Footer
- Logo + 产品名
- 一行说明

## 技术要点

- **帧动画**：JS 预加载 Image 对象数组，requestAnimationFrame 驱动，canvas drawImage
- **性能**：每个动画组按需加载（IntersectionObserver 触发预加载），悬停时才开始播放
- **视频**：`<video autoplay muted loop playsinline>`，移动端降级显示静态图
- **响应式**：移动端状态卡片2列，视频降级
